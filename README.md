# Velora Store

A fully working ecommerce boutique: browse products, search, save to a wishlist, add to bag, apply promo codes, and check out.

## Open it locally

Open `index.html` in a browser, or from this folder run:

```bash
python -m http.server 4173
```

Then visit http://localhost:4173

## Try the shop

- Promo codes: `VELORA10` (10% off), `WELCOME15` (15% off), `FREESHIP`
- Free shipping over $120
- Checkout is a complete demo — no real card is charged
- Cart, wishlist, and orders stay in this browser
